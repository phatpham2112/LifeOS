# Notion — Setup tối giản

Chỉ cần một database **Tasks** và một trang **Weekly Review**.

## Tasks database
| Property | Type | Ví dụ |
|---|---|---|
| Name | Title | Implement create task API |
| Status | Status | Backlog / In Progress / Blocked / Done |
| Priority | Select | High / Medium / Low |
| Feature ID | Text | FEAT-001 |
| Area | Select | Backend / Frontend / DevOps / Learning |
| Git link | URL | Link issue / PR |

## Quy tắc
- Notion: quản lý tiến độ.
- Git Markdown: nguồn tài liệu kỹ thuật.
- Không nhân bản nội dung tài liệu giữa Notion và Git.
- Mỗi tuần chọn tối đa 1–3 task trọng tâm.

## Weekly Review
1. Kết quả cụ thể tuần này?
2. Việc chưa xong và lý do?
3. Điều kỹ thuật đã học được?
4. Blocker lớn nhất?
5. Một kết quả quan trọng nhất tuần tới?
